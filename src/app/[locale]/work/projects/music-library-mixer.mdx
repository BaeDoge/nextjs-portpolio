## 프로젝트 배경

영상 촬영을 시작하면서 편집 과정에서 사용할 배경음악을 찾고, 영상 길이에 맞춰 여러 곡을 자르고 이어 붙이는 일이 반복됐습니다. 음악을 찾는 시간과 실제 편집 시간이 따로 들고, 영상 분위기에 맞는 곡을 다시 찾으려면 여러 사이트를 오가야 했습니다.

그래서 로컬에 보유한 음원과 외부 카탈로그를 하나의 라이브러리로 관리하고, 장르와 무드, 원하는 재생 시간을 기준으로 플레이리스트를 만들 수 있는 도구를 개발했습니다.

## 전체 작업 흐름

~~~text
음원 소스
  ├── Local Library
  ├── Jamendo
  ├── Openverse
  └── YouTube Audio Library (Optional)
        │
        ▼
Metadata 수집 및 SQLite 저장
        │
        ▼
Genre / Mood / Instrument / Vocal 분류
        │
        ▼
목표 길이에 맞는 곡 선택
        │
        ▼
Playlist 검토 및 편집
        │
        ▼
Download → Crossfade / Trim → FFmpeg
        │
        ▼
Mix 파일 + Timeline + Credits
~~~

## 라이선스와 외부 연동의 한계

<CalloutBox type="warning">
  라이선스 메타데이터와 자동 필터는 음원을 정리하기 위한 보조 기능이며, 특정 영상에 사용할 권리를 보증하지 않습니다. 게시하거나 수익화하기 전에 각 곡의 최신 라이선스와 원본 플랫폼 약관을 확인해야 합니다.
</CalloutBox>

특히 YouTube Audio Library 연동은 로그인된 YouTube Studio 브라우저 세션과 내부 웹 API 동작에 의존합니다. 안정적인 공개 API 계약이 아니므로 YouTube 측 화면이나 API가 바뀌면 수정이 필요할 수 있습니다. Jamendo 등 외부 소스 역시 각 서비스의 API 정책과 사용 조건을 따릅니다.

## AI 도구 활용과 개발 기여

영상 제작에 필요한 실제 작업 흐름을 먼저 정의하고, 라이브러리 구조와 곡 선택 기준, 플레이리스트 편집 방식을 직접 설계했습니다. AI 도구는 장르·무드 분류 기준을 정리하고 Provider 모듈과 편집 기능의 구현 대안을 검토하는 데 활용했습니다.

생성된 믹스는 실제로 재생해 보고, 곡 선택과 길이 계산, 편집 결과가 기대한 대로 동작하는지 확인하면서 개선했습니다. 자동화가 음원 사용 권리까지 판단해 주는 것은 아니라는 점도 명확히 구분했습니다.

## 정리

이 프로젝트는 음악 검색부터 최종 오디오 파일 생성까지 흩어진 작업을 한 흐름으로 연결한 도구입니다. 외부 API 연동뿐 아니라 메타데이터 모델, 선택 알고리즘, 오디오 처리와 라이선스 정보까지 함께 다뤄 볼 수 있었습니다.
