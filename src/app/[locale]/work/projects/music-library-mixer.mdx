## 프로젝트 개요

영상 편집을 할 때 장면의 분위기에 맞는 배경음악을 찾고, 영상 길이에 맞게 여러 곡을 편집하는 작업을 줄이기 위해 만든 음원 라이브러리입니다. 보유한 음원과 외부 카탈로그를 함께 관리하고, 원하는 장르·무드·재생 시간에 맞춰 믹스를 만들 수 있습니다.

## 주요 기능

- **음원 수집:** 로컬 보유 음원과 Jamendo, Openverse, YouTube Audio Library 카탈로그 연동
- **분류 및 검색:** 장르, 무드, 악기, 보컬 여부와 라이선스 정보 기반 분류
- **길이 기반 믹스:** 목표 재생 시간에 맞춰 곡을 선택하고, 크로스페이드와 마지막 구간 트리밍 지원
- **편집:** 생성된 플레이리스트에서 곡을 추가·삭제·이동하고, 제외한 곡은 자동 재선택에서 제외
- **결과물:** 통합 오디오 파일, 곡별 타임라인과 크레딧 정보 생성
- **사용 방식:** 데스크톱 메뉴와 CLI 모두 지원

## 구현

Python 기반으로 음원 메타데이터와 플레이리스트를 관리하고, 오디오 처리 도구를 이용해 최종 믹스를 생성합니다. 외부 서비스별 수집 코드는 Provider 단위로 분리해, 로컬 라이브러리만 사용하는 방식과 외부 카탈로그를 추가하는 방식을 선택할 수 있도록 했습니다.

| 영역 | 구성 |
| --- | --- |
| Language | Python 3.11 |
| Runtime | uv |
| Metadata | SQLite |
| Providers | Local, Jamendo, Openverse, YouTube Audio Library |
| Audio | FFmpeg / ffprobe |
| Optional browser integration | Playwright |

## 개발 과정

유튜브 영상 촬영을 시작하면서 매번 음원을 검색하고 길이를 맞추는 작업이 번거로워 직접 필요한 흐름을 정의했습니다. AI 도구는 장르·무드 분류 기준을 정리하고, 플랫폼별 수집 모듈과 플레이리스트 편집 흐름을 구현하는 과정에서 보조적으로 사용했습니다. 실제 다운로드와 믹스 결과를 들어보고, 선택이나 편집이 기대한 대로 동작하는지 확인하며 개선했습니다.

## 라이선스 관련 참고

음원 메타데이터와 라이선스 필터는 후보를 정리하는 보조 기능입니다. 특정 음원의 영상 사용이나 수익화를 보증하지는 않습니다. 공개 또는 수익화 전에 원본 플랫폼의 최신 약관과 곡별 라이선스를 확인하고, 저작자 표시가 필요한 경우 생성된 크레딧을 함께 제공해야 합니다. YouTube Audio Library 연동은 로그인된 YouTube Studio 브라우저 세션과 내부 웹 API 동작에 의존하므로, 플랫폼 변경에 따라 수정이 필요할 수 있습니다.
