## 프로젝트 배경

이미지 생성 모델에 프롬프트를 한 번 입력해 결과를 얻는 것만으로는 원하는 분위기의 그림을 안정적으로 만들기 어려웠습니다. 특히 짧은 만화처럼 여러 장면이 이어지는 콘텐츠는 장면별 설명, 그림 스타일, 후보 이미지 선택과 컷 구성을 함께 관리해야 했습니다.

이 프로젝트는 텍스트로 장면 흐름을 기획하고, 장면별 이미지 후보를 생성한 뒤, 결과를 비교하고 하나의 시퀀스로 구성하는 과정을 자동화하는 실험에서 출발했습니다. 최근에는 강아지, 고양이, 토끼처럼 단순하고 친근한 동물 캐릭터와 과한 디테일을 줄인 그림체를 중심으로 제작 방향을 구체화하고 있습니다.

### 1. 장면 기획과 스타일 구성

LLM이 주제와 장면 정보를 바탕으로 짧은 이야기 흐름을 만들고, 각 장면을 이미지 생성용 설명으로 바꿉니다. 그림 스타일은 코드에 정의된 프리셋에서 선택하고, 공통 긍정·부정 프롬프트를 결합해 장면마다 스타일이 크게 흔들리지 않도록 구성했습니다.

### 2. 이미지 후보 생성

로컬 GPU에서 Diffusers의 Stable Diffusion XL 파이프라인을 실행합니다. 장면마다 여러 후보를 생성하고, seed를 기록해 같은 조건의 결과를 다시 확인할 수 있도록 했습니다. 모델 경로와 LoRA 적용 여부, CPU offload 등은 환경 설정으로 조정합니다.

## 개발 환경과 실행 방식

현재 공개 저장소는 Python 3.11 기반이며, PyTorch와 Diffusers를 사용해 CUDA GPU에서 이미지 생성을 수행합니다. 기본 모델은 SDXL 계열을 사용하고, 필요하면 별도 체크포인트나 LoRA를 지정할 수 있도록 구성했습니다.

~~~bash
uv sync
python main.py check
~~~

데모 모드에서는 테스트용 입력으로 기획 흐름과 이미지 생성 결과를 확인할 수 있습니다. 이미지 생성은 모델 파일과 CUDA 환경이 준비된 GPU에서 수행해야 합니다.

## 현재 구현 범위와 한계

<CalloutBox type="warning">
  현재 저장소는 이미지 생성과 장면 구성 파이프라인을 검증하는 실험 구현입니다. VLM을 연결하지 않은 경우 이미지 의미 검증은 CLIP 점수와 기본 품질 검사에 의존합니다. 또한 여러 컷에 걸친 캐릭터의 외형·의상·비율을 항상 동일하게 유지하는 기능은 보장하지 않으며, 일관된 캐릭터 생성을 위한 참조 이미지와 추가 학습 방식은 계속 실험할 영역입니다.
</CalloutBox>

일부 실행 흐름은 특정한 다중 컷 콘텐츠 포맷에 맞춰져 있어, 범용 이미지 편집기나 완성된 만화 제작 도구와는 범위가 다릅니다. 현재는 프롬프트 기획, 후보 생성, 이미지 비교와 컷 구성 과정을 분리해 개선하기 쉬운 형태로 만드는 데 집중하고 있습니다.

## AI 도구 활용과 개발 기여

이미지 생성 모델의 결과를 무작정 많이 만드는 데서 끝내지 않고, 어떤 장면을 만들지 정하고 결과를 비교해 선택하는 파이프라인을 직접 기획했습니다. AI 도구는 장면 구성, 프롬프트 구조, 검증 기준과 생성 코드의 대안을 검토하는 데 사용했습니다. 모델 설정과 생성 결과는 GPU 환경에서 직접 실행해 확인하고, 이미지 품질과 장면 적합성을 기준으로 코드를 수정했습니다.

## 정리

이 프로젝트를 통해 생성형 이미지 모델을 호출하는 것뿐 아니라, 장면 기획과 프롬프트 설계, 복수 후보 생성, 결과 검증과 컷 구성까지 이어지는 과정을 다뤄볼 수 있었습니다. 앞으로는 캐릭터의 시각적 특징을 안정적으로 유지하고, 하나의 캐릭터가 여러 장면에서 자연스럽게 이어지는 이미지와 짧은 만화를 만드는 방향으로 발전시키고 있습니다.
