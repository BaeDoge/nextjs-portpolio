## 프로젝트 개요

사내 밴드 동호회 공연을 준비하면서 공연 일정, 장소, 멤버, 셋리스트와 같은 정보를 한곳에서 전달할 수 있는 모바일 웹 초대장을 만들었습니다. 단순한 행사 안내 페이지에 그치지 않고, 관객이 공연 전후로 페이지에 참여하고 기록을 남길 수 있도록 구성했습니다.

운영 중인 페이지는 [BAND NIGHT](https://daeil-band.vercel.app)에서 확인할 수 있습니다.

## 주요 기능

- **공연 안내:** 공연 일정, 장소, 지도, 멤버 소개와 셋리스트 제공
- **관객 참여:** 닉네임 등록, 이모티콘 응원, 질문 및 뒤풀이 참석 응답
- **운영자 화면:** 방문 현황, 응원 및 질문 내역, 참석 응답 확인과 사용자 관리
- **공연 기록:** 행사 사진을 보여주는 갤러리와 공연 종료 후에도 유지되는 추억 아카이브
- **운영 안정성:** 행사 종료 후에는 주요 콘텐츠를 정적 페이지로 제공해 데이터베이스 상태에 대한 의존성을 줄임

## 구현

Next.js 기반으로 모바일 화면을 우선 설계하고, 관객 참여 데이터와 운영자 기능은 Supabase에 연결했습니다. Vercel 배포를 통해 별도 앱 설치 없이 QR 코드나 링크로 접속할 수 있도록 했습니다.

| 영역 | 구성 |
| --- | --- |
| Frontend | Next.js, React, JavaScript |
| Database | Supabase |
| Deployment | Vercel |
| Media | Responsive images, video and WebP assets |

## 기획 및 개발 과정

공연을 준비하는 과정에서 실제로 필요한 정보와 관객의 이용 흐름을 먼저 정리하고, 이를 화면과 데이터 구조로 옮겼습니다. ChatGPT 등 AI 도구는 UI 대안 검토, API 흐름 정리, SQL 변경 사항 초안 작성과 오류 분석에 활용했습니다. 생성된 코드를 그대로 적용하기보다 모바일 브라우저와 실제 배포 환경에서 동작을 확인하고, 운영하면서 드러난 요구사항을 반영해 수정했습니다.

기획부터 기능 우선순위 결정, 구현, 배포와 운영 개선까지 직접 진행한 프로젝트입니다.

## 설계 시 고려한 점

관객은 별도 계정 가입 없이 참여할 수 있도록 브라우저 식별자를 사용합니다. 따라서 사용자 차단 기능도 계정 단위가 아닌 브라우저 단위로 동작하며, 다른 기기나 시크릿 모드에서는 동일 사용자를 식별하지 못할 수 있습니다. 일반적인 인증 서비스와 동일한 수준의 사용자 인증을 제공하는 구조는 아닙니다.

공연이 끝난 뒤에도 안내 페이지가 남을 수 있도록, 종료 이후에는 참여 기능을 숨기고 정적 사진 아카이브를 중심으로 제공하도록 설계했습니다.
