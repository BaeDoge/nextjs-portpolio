## 프로젝트 개요

BUYMA에서 판매하는 상품의 경쟁 가격을 반복해서 확인하고 직접 수정하는 작업을 줄이기 위해 만든 자동화 프로그램입니다. Google Sheets에 정리된 상품 URL을 읽어 경쟁 가격을 비교하고, 조건을 만족하는 상품에 한해 BestShip 판매 상품의 가격 변경을 요청합니다.

## 주요 기능

- **가격 비교:** Google Sheets에 등록된 BUYMA URL을 읽고 경쟁 상품의 가격을 비교
- **변경 기준 설정:** 경쟁 최저가와의 차액(delta), 한 번에 변경할 수 있는 최대 금액(max_change) 설정
- **미리보기:** 변경 대상과 계산된 가격을 먼저 확인한 뒤 단일 상품 또는 전체 상품 처리
- **가격 변경:** BUYMA Personal Shopper Product API를 통해 변경 요청
- **실행 이력:** Google Sheets와 CSV에 실행 결과 및 변경 내역 기록
- **예약 실행:** 지정한 시간에 반복 실행하고 Windows 실행 파일로 패키징

## 구현 구성

| 영역 | 구성 |
| --- | --- |
| Language | Python 3.11 |
| Environment | uv |
| External services | BUYMA Product API, Google Sheets API |
| Browser automation | Playwright |
| Testing | pytest |
| Distribution | Windows executable build |

실행은 메뉴형 프로그램과 예약 실행 프로그램으로 나누었습니다. 기본 흐름은 가격 비교와 미리보기이며, 실제 변경은 사용자가 확인한 뒤 진행하도록 구성했습니다.

## 개발 과정

가격 변경 로직에서 가장 중요했던 부분은 무조건 최저가를 따라가는 것이 아니라, 허용한 범위 안에서만 가격을 조정하는 것이었습니다. 기준값과 예외 조건을 설정 파일로 분리하고, 단일 상품 테스트와 전체 상품 실행을 구분해 실수로 대량 변경이 일어나지 않도록 했습니다.

AI 도구는 가격 정책과 실행 흐름을 정리하고, API 연동 코드와 테스트 케이스를 다듬는 과정에서 보조적으로 활용했습니다. 실제 상품 운영에 맞는 기준과 변경 여부는 제가 직접 판단하고 확인하도록 만들었습니다.

## 테스트 및 주의사항

자동 테스트는 모의 HTTP 응답과 Google Sheets 객체를 사용합니다. 따라서 테스트 통과가 실제 BUYMA 계정에서의 가격 변경 성공을 의미하지는 않습니다. 실제 연동에는 사용자의 BUYMA 인증 정보, API 권한과 Google 서비스 계정 설정이 필요합니다. 타임세일 상품의 처리 여부도 설정값에 따라 달라집니다.
