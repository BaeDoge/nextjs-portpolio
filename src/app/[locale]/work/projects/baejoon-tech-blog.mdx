## 프로젝트 개요

개발하면서 마주친 오류와 해결 과정, 알고리즘 풀이, 관심 있는 논문과 오픈소스 프로젝트를 꾸준히 정리하기 위해 만든 기술 블로그입니다. 단순히 글을 모아두는 데서 끝나지 않고, 코드와 설명을 함께 보며 직접 실습할 수 있는 학습 공간을 목표로 했습니다.

운영 사이트는 [Baejoon](https://baejoon.vercel.app)입니다. 이름은 알고리즘 문제 풀이 사이트인 백준에서 착안했습니다.

## 주요 기능

- **주제별 콘텐츠:** 알고리즘, 트러블슈팅, 논문 리뷰, 오픈소스 분석
- **MDX 기반 글 관리:** 코드와 시각 요소를 본문에 함께 구성
- **탐색 기능:** 카테고리 목록, 사이트 검색, 관련 글과 예상 읽기 시간
- **실습 중심 콘텐츠:** 문제 해결 과정과 코드 예제를 함께 제공
- **검색 및 공유:** 메타데이터, canonical URL, sitemap, robots.txt와 구조화 데이터

## 구현

Next.js App Router와 MDX를 중심으로 콘텐츠를 관리합니다. 글은 카테고리별 디렉터리에 Markdown/MDX 파일로 추가할 수 있어, 새로운 주제를 기록하거나 기존 글을 수정하기 쉽도록 구성했습니다. Vercel 배포를 통해 GitHub 변경 사항을 사이트에 반영합니다.

| 영역 | 구성 |
| --- | --- |
| Frontend | Next.js App Router, React |
| Content | MDX, Markdown |
| Styling | CSS |
| Deployment | Vercel |

## 기획 및 운영

어떤 글을 만들지 정하는 것부터 자료를 확인하고 예제를 실행해 보는 과정까지 직접 진행합니다. ChatGPT 등 AI 도구는 논문과 기술 주제를 탐색하고, 설명 구조를 잡거나 코드 초안을 검토하는 데 활용합니다. 다만 검색 결과나 생성된 설명을 그대로 게시하지 않고, 원문과 출처를 확인하고 예제를 직접 실행해 수정하는 것을 원칙으로 합니다.

콘텐츠가 쌓일수록 단순한 개인 기록을 넘어, 개발 과정에서 다시 찾아볼 수 있는 실용적인 지식 저장소로 발전시키는 것이 목표입니다.
