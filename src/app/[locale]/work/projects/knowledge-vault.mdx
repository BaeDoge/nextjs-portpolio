## 프로젝트 개요

업무 중 알게 된 내용이나 반복적으로 참고하는 해결 방법이 개인의 기억과 메신저, 문서에 흩어지면 같은 내용을 다시 찾는 데 시간이 걸립니다. 이런 정보를 카테고리와 태그로 정리하고, 필요한 순간 빠르게 찾아볼 수 있도록 개인 및 팀용 지식 저장소를 만들었습니다.

## 주요 기능

- **지식 등록 및 수정:** 제목, 본문, 카테고리와 태그를 함께 관리
- **전문 검색:** SQLite FTS5를 활용해 제목과 본문, 태그를 검색
- **카테고리 관리:** 업무 성격에 맞게 카테고리를 추가·삭제
- **첨부파일:** 지식 항목에 관련 파일을 연결
- **CLI:** 터미널에서 서버의 지식을 검색하고 조회
- **백업:** 데이터베이스와 첨부파일을 보존하기 위한 백업 스크립트 제공

## 구현

FastAPI와 SQLite를 기반으로 별도 데이터베이스 서버 없이 실행할 수 있도록 구성했습니다. SQLite FTS5를 통해 전문 검색을 제공하고, 지식 항목과 카테고리, 첨부파일 메타데이터를 분리해 관리합니다. 브라우저 UI와 CLI가 동일한 API를 사용하도록 구성했습니다.

| 영역 | 구성 |
| --- | --- |
| Backend | Python, FastAPI |
| Database / Search | SQLite, FTS5 |
| Template | Jinja2 |
| Runtime | uv, Uvicorn |

## 기획 및 개발 과정

어떤 정보를 저장할지보다 나중에 다시 찾기 쉬운 구조를 만드는 데 중점을 두었습니다. 카테고리와 태그, 전문 검색을 기본으로 두고, 기존 지식을 수정하거나 첨부파일과 함께 보관할 수 있도록 기능을 구성했습니다.

AI 도구는 데이터 구조와 검색 흐름을 검토하고, CLI와 API의 반복 구현을 보조하는 데 활용했습니다. 업무 노하우를 어떤 단위로 기록하고 어떻게 분류할지는 직접 정했으며, 실제 사용 흐름을 기준으로 기능을 다듬었습니다.

## 사용 환경

현재 구현은 별도 계정 시스템이나 조직 단위 권한 관리를 제공하는 제품이 아니라, 개인 또는 신뢰할 수 있는 내부 환경에서 직접 운영하는 경량 도구입니다. 업무 자료를 저장해 사용할 때에는 실행 환경의 접근 권한과 백업 위치를 별도로 관리해야 합니다.
