## Background

After I started filming videos, I found myself repeatedly searching for suitable background music and trimming or combining tracks to fit each clip. Finding music and editing it were separate tasks, and exploring several catalogs to match a particular mood added more overhead.

I built a tool that manages locally owned tracks and selected external catalogs in one library, then creates playlists based on genre, mood, and target duration.

## End-to-end Workflow

~~~text
Music sources
  ├── Local Library
  ├── Jamendo
  ├── Openverse
  └── YouTube Audio Library (Optional)
        │
        ▼
Collect metadata and store in SQLite
        │
        ▼
Classify by Genre / Mood / Instrument / Vocal
        │
        ▼
Select tracks for the target duration
        │
        ▼
Review and edit the playlist
        │
        ▼
Download → Crossfade / Trim → FFmpeg
        │
        ▼
Mix file + Timeline + Credits
~~~

## Licensing and External Integration Limits

<CalloutBox type="warning">
  License metadata and automatic filters help organise tracks; they do not grant usage rights or guarantee that a track is suitable for a particular video. Before publishing or monetising, check the current license for each track and the source platform's terms.
</CalloutBox>

The YouTube Audio Library provider relies on an authenticated YouTube Studio browser session and internal web endpoints. These are not a stable public API contract, so changes on YouTube's side may require maintenance. External catalogs such as Jamendo are also subject to their own API policies and usage terms.
