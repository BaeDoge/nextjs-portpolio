## Background

Configuration notes and solutions to recurring problems often become scattered across chat messages, personal documents, and browser bookmarks. When the same problem appears again, it can take time to find the relevant notes and reconstruct what was done.

I built a knowledge store that organises this information with categories and tags, keeps related files alongside each entry, and makes it searchable by keyword.

## Search Design

SQLite FTS5 indexes titles, content, and tags. Database triggers keep the search index in sync when knowledge entries are inserted, updated, or deleted.

## Design Considerations

### Lightweight operation

The project is intended for personal or small internal use, so I chose SQLite instead of operating a separate database server. The application uses WAL mode and foreign keys, and provides a way to back up the database together with its attachments.

### Making information easy to retrieve

A large collection of notes is not useful if the information cannot be found when needed. Categories and tags provide secondary organisation, while full-text search is the primary way to retrieve entries.

<CalloutBox type="warning">
  The current implementation is a lightweight self-hosted tool. It does not provide multi-user authentication or organisation-wide permissions. When storing work materials, run it on localhost or a trusted internal network and manage access to the data directory and backup files separately.
</CalloutBox>

## AI-assisted Development and My Contribution

I prioritised a structure that would make information easy to retrieve months later, not simply easy to save. I designed the knowledge-entry model, category management, FTS5 search flow, and attachment handling.

AI tools helped me review the data model and search approach, draft repetitive API and CLI code, and investigate errors. I tested and revised the implementation to ensure that search results fit the intended workflow and that entries and attachments remained consistently managed.

## Takeaways

Knowledge Vault is more than a note-taking page: it is a small platform for structuring recurring work knowledge and finding it again when needed. The project gave me practical experience combining a search index, attachment storage, an API, and a CLI around a single data model.
