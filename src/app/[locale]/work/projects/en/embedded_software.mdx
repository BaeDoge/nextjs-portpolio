## Project Overview

This is the "Brushing Basics" project, which started from the idea:
what if we could analyze brushing habits with a single camera, without an expensive smart toothbrush?

The system collects video of the brushing hand with a Raspberry Pi camera on an embedded board,
analyzes the brush direction and missed areas with an LSTM deep learning model, and shows the result on the web.
I built it with four colleagues from my lab, and because we divided the roles well from the start, we collaborated smoothly.

## Deep Learning Model

I extract a total of **36 landmark coordinates** from MediaPipe: 21 for the hand and 15 for the face.
I also collect the Euclidean distance between the current frame and the previous frame.
This is so the model learns the user's movement pattern rather than absolute positions in the video.

```python
# Feed 60 frames (about 1 second) of sequential data into the LSTM
model = Sequential([
    LSTM(64, return_sequences=False, input_shape=(60, 36*3)),
    Dense(32, activation='relu'),
    Dropout(0.3),
    # + Hidden Layers
    Dense(4, activation='softmax')  # 4 brushing-direction classes
])
```

I trained and fine-tuned on varied conditions (brightness, distance, face direction), including left-handed and right-handed users.
