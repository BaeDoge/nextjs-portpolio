## Overview

I created this technical blog to document the problems I encounter while developing, the solutions I try, algorithm exercises, and research or open-source projects that I find useful. The goal is not just to collect articles, but to make each topic easier to explore through explanations and practical code examples.

The live site is [Baejoon](https://baejoon.vercel.app). The name takes inspiration from Baekjoon, the well-known algorithm practice platform in Korea.

## Features

- **Topic-based content:** Algorithms, troubleshooting, paper reviews, and open-source analysis
- **MDX authoring:** Combines written explanations, code, and visual components
- **Content discovery:** Category pages, site search, related posts, and estimated reading time
- **Hands-on learning:** Presents problem-solving steps alongside code examples
- **Search and sharing:** Metadata, canonical URLs, sitemap, robots.txt, and structured data

## Implementation

The site uses Next.js App Router and MDX. Articles are stored as Markdown or MDX files grouped by category, making it straightforward to add new topics and revise existing posts. GitHub changes are deployed through Vercel.

| Area | Technologies |

## Planning and Editorial Process

I choose the topics, review source material, and run code examples as part of preparing an article. AI tools such as ChatGPT help me explore technical topics, organise explanations, and review code drafts. I do not publish generated answers without checking them: I verify original sources, test examples, and edit the content based on the results.

As the collection grows, I want Baejoon to become a practical reference that I can return to during future development, rather than just a personal diary.
