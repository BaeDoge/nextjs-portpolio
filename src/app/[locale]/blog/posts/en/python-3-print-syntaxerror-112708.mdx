## Symptom

In Python 3.1 or later environments, using `print` without parentheses, such as `print 2 ** 100`, results in a `SyntaxError: invalid syntax`.
The error message points to the `2` number, which occurs because `print` was changed from a statement to a function in Python 3.

```python
print 2 ** 100
# SyntaxError: invalid syntax
```

## Cause

Python 3 redefined `print` as a built-in function to increase syntactic flexibility.
The existing Python 2 `print` statement allowed listing arguments without parentheses, but Python 3 requires the function call format with parentheses `()`.
Omitting the parentheses causes the interpreter to recognize the syntax as invalid, triggering an error before execution.

## Solution

Wrap the value to be printed in parentheses `()` after `print` to change it to a function call format.

```python
# Before modification (Python 2 style)
print 2 ** 100

# After modification (Python 3 style)
print(2 ** 100)
```

## Alternative Solutions

The `print` function in Python 3 supports various keyword arguments to control output formatting.
To accurately reproduce the behavior of the existing Python 2 `print` in Python 3, explicitly specify arguments such as `end` and `file`.

```python
# Python 2: print x,  (adds a space at the end, no newline)
# Python 3 equivalent:
print(x, end=" ")

# Python 2: print >>sys.stderr, "error"
# Python 3 equivalent:
print("error", file=sys.stderr)
```

## Additional Notes

The difference in `print` syntax between Python 2 and Python 3 is one of the most common errors encountered during the initial learning phase.
The following table compares the main changes.

<Callout type="info" title="Caution">
In Python 3, `print (x, y)` receives the tuple `(x, y)` as a single argument and prints it.
To print two values separated by a space like Python 2's `print x, y`, you must write `print(x, y)`.
</Callout>
