## The Reality of Medical Data Analysis and the Problem to Solve

Biomedical research deals with increasingly large and complex data every year, making the time and expertise required for analysis a major barrier. Performing data processing and analysis directly requires immense manpower and time from researchers.

This study proposes an open-source agentic AI co-researcher named `OpenScientist` to solve these problems. This system aims to automate the process of answering researcher-defined questions and generate verifiable, data-driven analysis results. Beyond simply producing results, it emphasizes making the analysis process itself transparent so that researchers can trust it.

## Core Features and Workflow of OpenScientist

`OpenScientist` is designed to support the actual scientific discovery process, going beyond general chatbots or summarization tools. Its main features operate in the following workflow:

```flow
Researcher's query input
→ Literature research and hypothesis generation
→ Data analysis code generation and execution
→ Verifiable results and insights generation
```

The system first investigates relevant literature and generates hypotheses. Then, it automatically writes and executes analysis code based on the data provided by the researcher. The generated code must be reproducible, and the analysis results must be clearly based on the data. Through this process, researchers can focus on core scientific questions without getting bogged down in complex data processing procedures.

## Performance and Applicability Based on Real-World Cases

The paper introduces that `OpenScientist` was evaluated by domain experts across five biomedical case studies. The analysis cases included quantifying Alzheimer's disease serum biomarker performance, generating plasma proteomics-based survival prediction models, and proposing association mechanisms between tau pathology and lysosomal acidification.

A key advantage is the time required for analysis. Analysis tasks that would take experts months to perform were completed by `OpenScientist` in just a few minutes. This suggests a fundamental improvement in the efficiency of the research cycle, beyond simple speed enhancement. In addition, some hypotheses were validated in external cohorts, and the analysis results were found to match those of human analysts.

## Security Design for Handling Sensitive Medical Data

Because medical data contains sensitive personal information, transmission to external networks is often restricted. `OpenScientist` is designed to be utilized even in such environments.

The system can operate in a completely isolated air-gapped environment. To achieve this, it uses open-source models for inference and can perform analysis tasks locally without external dependencies. This serves as a practical solution enabling the adoption of AI technology even in environments with strict security policies inside hospitals or research institutes.

## Key Takeaways for Developers and Researchers

`OpenScientist` is not a tool to discover treatments for specific diseases, but a "co-researcher" that assists with data analysis. From a developer's perspective, the value provided by this system is as follows.

First, **open source and verifiability**. The analysis process must be transparently disclosed and reproducible to be recognized as a reliable scientific tool. `OpenScientist` follows these principles.

Second, **air-gap support**. The ability to run locally in security-critical fields like medical data analysis can be the biggest advantage during actual deployment.

Third, the point that it must be **used under expert supervision**. AI-generated results must ultimately be verified and interpreted by human experts. AI is merely a tool that increases the speed and efficiency of analysis, and the leadership of scientific insight still rests with humans.

This study is an example showing that agentic AI can support the complex scientific discovery process itself, going beyond simple coding assistance. It is significant in that it proposes applicability in areas where data sensitivity and accuracy are simultaneously required, such as the medical field.
