## Symptom

An `UnboundLocalError` occurs when attempting to modify the value of a variable from an outer function within a nested function.

<Callout type="warning" title="Error Situation">
UnboundLocalError: local variable 'ctr' referenced before assignment
</Callout>

The code to reproduce the error is as follows.

```python
def outer():
    ctr = 0

    def inner():
        ctr += 1

    inner()

outer()
```

![Symptom screenshot](/blogs/unboundlocalerror-141938-1.png)

## Cause

In Python, if a variable is assigned to (using `+=`, `=`, etc.) inside a function, that variable is treated as a **local variable**.

When the statement `ctr += 1` is executed in the `inner` function, the interpreter treats `ctr` as a local variable. However, since the code attempts to read the current value of the variable before assigning a new value to it, an error occurs indicating that a local variable that has not been assigned to is being referenced.

## Solution

In Python 3, you can use the `nonlocal` keyword to allow reassignment of variables from an outer scope.

```python
def outer():
    ctr = 0

    def inner():
        nonlocal ctr
        ctr += 1

    inner()
```

By adding `nonlocal ctr`, the `inner` function recognizes `ctr` as a variable in the `outer` function's scope rather than a local variable, allowing its value to be modified.

![Solution screenshot](/blogs/unboundlocalerror-141938-2.png)

## Alternative Solutions

Instead of using `nonlocal`, you can use a mutable object to change the internal value without reassigning the variable itself.

```python
def outer():
    ctr = [0]

    def inner():
        ctr[0] += 1

    inner()
```

This approach does not violate scope rules because it modifies the value inside the list object rather than reassigning the `ctr` variable itself.

## Additional Notes

Use the `global` keyword to modify the value of a global variable.

```python
ctr = 0

def inner():
    global ctr
    ctr += 1

inner()
```

If not declared with `global`, the same error occurs due to the difference between global and local variables. Therefore, you must choose the appropriate keyword depending on whether the target of modification is a global variable or a variable in an outer function.
