## Symptom

Dictionaries raise a `KeyError` for missing keys but allow setting a default value via the `get()` method for exception-free access.
In contrast, lists raise an `IndexError` when accessing an out-of-bounds index, and lists do not have a built-in `get()` method for this purpose.

```python
>>> d = {'a':'b'}
>>> d.get('c', 'fail')
'fail'

>>> l = [1]
>>> l[10]
IndexError: list index out of range
```

<Callout type="warning" title="Error Scenario">
You cannot directly use a feature equivalent to `dict.get()` to prevent execution from stopping due to index errors in lists.
</Callout>

![Symptom screenshot](/blogs/python-list-safe-get-1.png)

## Cause

Dictionaries are collections of name-value pairs, where checking for key existence and returning values is efficiently linked to the exception-throwing mechanism.
Lists are ordered collections, where checking the length via the `len()` method during index access is very low-cost.
Since the exception-throwing mechanism (`IndexError`) during index access is sufficiently efficient, the design does not require a separate `get()` method.

## Solution

To implement a safe access method that returns a default value in lists, you must catch the `IndexError` using a `try-except` block.

```python
def safe_list_get(l, idx, default):
  try:
    return l[idx]
  except IndexError:
    return default
```

## Alternative Solutions

Monkey-patching the built-in `list` type to add a `get` method is not recommended as it affects all code globally.
Instead, you can define a subclass that inherits from `list` and adds a `get` method, applying this functionality only to specific list instances used in your code.

```python
class SafeList(list):
    def get(self, idx, default=None):
        try:
            return self[idx]
        except IndexError:
            return default
```

## Additional Notes

The `dict.get()` method is optimized for retrieving values by key, differing from data structures like lists that retrieve values by index.
List index errors are more suitable for exception handling mechanisms that immediately signal a mismatch between the index value and the data length.
