## Problem

Given a string `s`, return the number of palindromic substrings contained within it. A palindrome is a string that reads the same forward and backward. A substring is a contiguous sequence of characters within the string. For example, in "abc", there are three palindromic substrings: "a", "b", and "c". In "aaa", there are six palindromic substrings: "a", "a", "a", "aa", "aa", and "aaa". The length of the string is at most 1000, and it consists of lowercase English letters.

## Approach

Use two pointers starting from each character in the original string to expand outward and check if the substring is a palindrome. For each position, count the number of palindromic substrings centered at that position and sum them up. This method considers each character as a center and checks for both odd-length and even-length palindromes.

## Solution

```python
def countSubstrings(s: str) -> int:
    n = len(s)
    count = 0
    for i in range(n):
        # Odd center: s[i]
        left, right = i, i
        while left >= 0 and right < n and s[left] == s[right]:
            count += 1
            left -= 1
            right += 1
        # Even center: s[i] and s[i+1]
        left, right = i, i + 1
        while left >= 0 and right < n and s[left] == s[right]:
            count += 1
            left -= 1
            right += 1
    return count
```

Time Complexity: O(n²), Space Complexity: O(1)

## Alternative Approaches

A dynamic programming (DP) approach is also possible. Use `dp[i][j]` to store whether the substring `s[i..j]` is a palindrome. This method requires O(n²) time and O(n²) space, although the code may be more complex. Both approaches have the same time complexity, but DP uses more memory.

## Additional Notes

- Example 1: "abc" → 3 (each single character)
- Example 2: "aaa" → 6 (3 singles, 2 "aa"s, 1 "aaa")
- Both odd-length and even-length centers must be considered to obtain the correct result.
- Ensure the conditions `left >= 0` and `right < n` are used in the while loop to prevent index out-of-bounds errors.
