## Symptom

When running tests with Flask 2.2.2, an error occurs because `url_quote` cannot be imported from the `werkzeug.urls` module. The error message is as follows:

<Callout type="warning" title="Error Situation">
ImportError: cannot import name 'url_quote' from 'werkzeug.urls'
</Callout>

The minimal environment and traceback that trigger the error are as follows:

```text
# 환경
Python 3.10.11
Flask==2.2.2
Werkzeug==3.0.0 (자동 설치됨)

Traceback (most recent call last):
  File ".../flask/app.py", line 30, in <module>
    from werkzeug.urls import url_quote
ImportError: cannot import name 'url_quote' from 'werkzeug.urls'
```

## Cause

Flask 2.2.2 references `werkzeug.urls.url_quote`, but this function was removed in Werkzeug 3.0.0. Because Flask 2.2.2's dependency specification only sets a lower bound of `Werkzeug>=2.2.0` without an upper bound, the package manager can automatically install the latest Werkzeug 3.0.0, causing an ImportError.

## Solution

Pin a compatible version of `Werkzeug` in the `requirements.txt` file.

```
# requirements.txt
Flask==2.2.2
Werkzeug==2.2.2
```

Reinstall the packages to align versions.

<Terminal title="Run Command">
pip install -r requirements.txt
</Terminal>

## Alternative Solutions

Update `Flask` to the latest version to make it compatible with `Werkzeug 3.0.0`.

```
# requirements.txt
Flask==3.0.0
```

After updating, reinstall the packages to resolve dependencies.
