Today I'll write up how I cleaned up my VS Code settings.

## Background

While setting up a new laptop, I checked my old `settings.json` and found it had grown past 300 lines, and I couldn't remember what many of the entries were for.

## Approach

I reset the settings and rebuilt them by adding items only when I needed them.

## Settings that remained after two weeks

```jsonc
{
  "editor.formatOnSave": true,
  "editor.renderWhitespace": "boundary",
  "files.exclude": {
    "**/__pycache__": true,
    "**/.pytest_cache": true,
    "**/node_modules": true
  },
  "search.exclude": {
    "**/dist": true,
    "**/.next": true,
    "**/package-lock.json": true
  },
  "editor.minimap.enabled": false,
  "files.autoSave": "off"
}
```

It came down to about 20 lines.

## What I dropped

- Font ligatures: showing certain operators in a different form actually hurt readability
- Custom bracket colors: the defaults were enough
- Many theme-related settings: unnecessary once I settled on a theme

## Cleaning up extensions

I cut 35 extensions down to 9, using "whether I actually used it in the last two weeks" as the criterion.

## Conclusion

Settings tend to accumulate over time, and if they aren't cleaned up periodically, they become hard to make sense of. I plan to keep reviewing them regularly.
