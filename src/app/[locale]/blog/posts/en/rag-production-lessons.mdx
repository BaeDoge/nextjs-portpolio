## 1. How to Build Chunks

In the financial FAQ domain, chunking by question-answer pair gave better retrieval accuracy than splitting by character count.

```python
def chunk_by_qa(document: str) -> list[str]:
    chunks = []
    qa_pairs = re.split(r'\n(?=Q:)', document)
    for pair in qa_pairs:
        if pair.strip():
            chunks.append(pair.strip())
    return chunks
```

## 4. Handling Streaming

```typescript
const stream = await groq.chat.completions.create({
  model: "llama-3.3-70b-versatile",
  messages: [...],
  stream: true,
});
```

Setting `stream: true` outputs the response in real time, which shortened the perceived waiting time.

## Conclusion

Building a RAG system and operating one turned out to be separate problems. The chunking strategy, prompt history management, and monitoring setup had a direct effect on operational stability.
