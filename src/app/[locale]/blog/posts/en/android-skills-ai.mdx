## Project at a Glance and the Problem It Solves

`android/skills` is a repository of "modular AI optimization guidelines" designed to help AI agents in the Android development ecosystem understand and execute specific domains or workflows more accurately. This project is not just a library of code snippets, but a collection of "technical specifications" that help Large Language Models (LLMs) accurately grasp and execute the complex requirements of Android development.

Currently, many LLM-based coding tools are proficient in general Jetpack Compose patterns or basic Android API usage. However, they often exhibit hallucinations or reference outdated information in specialized areas, such as migration strategies for specific libraries, complex hardware integration (camera, automotive, etc.), or changes in modern build systems. To address these issues, `android/skills` provides standardized `SKILL.md` files in Markdown format based on official guides from [developer.android.com](https://developer.android.com) for agents to reference. In short, this repository serves as a knowledge base and interface that makes an AI act like an "Android expert" when developers use it to build Android apps.

## Key Concepts Needed to Understand It

To understand this project, you need to grasp these three core concepts:

1. **SKILL.md (Open Standard Agent Skills):** Markdown files that follow the [agentskills.io](https://agentskills.io/home) standard. These serve to clearly communicate the technical specifications and constraints of a specific task to an agent. Beyond just reading text, they provide "grounding" information for the agent to perform tasks.
2. **AI Agent Plugins:** This repository is not an independent executable but is installed as a plugin for AI agent tools like Claude Code or Codex. Configuration files such as `.claude-plugin/plugin.json` or `.codex-plugin/plugin.json` define how the agent explores and applies the knowledge in this repository.
3. **Workflow-based Knowledge Structure:** Unlike general documentation, this repository is organized into folders by "skill." For example, the `camera/camerax/` folder systematically organizes references needed for actual development workflows, such as migration, testing, and performance optimization, alongside camera-related technical specifications.

## Repository Structure and Actual Flow

The repository is structured hierarchically by technical domain. Key folder structures include:

- `build-system/`: Knowledge related to Android Gradle Plugin (AGP) upgrades and build optimization.
- `camera/`: Guides for utilizing the CameraX library and hardware integration.
- `device-ai/`: Technical specifications for implementing on-device AI, such as LiteRT and ML Kit.
- `jetpack-compose/`: Guidelines for UI migration, performance optimization, and adaptive layouts.
- `identity/`: Guides for security authentication, such as Passkeys and Credential Manager.

**Flow of Operation:**
1. **Installation:** Users add specific skills to a project via `android-cli`. For example, running `android skills add r8-analyzer --project=.` imports a knowledge set locally that allows the project's agent to understand R8 optimization rules.
2. **Exploration:** The agent analyzes the user's prompt (e.g., "Make my app UI edge-to-edge"). If the relevant skill is installed, the agent searches the skill's `SKILL.md` and reference documents to verify the latest API usage.
3. **Execution:** The agent generates or modifies code based on the verified knowledge. If auxiliary scripts like `performance/r8-analyzer/scripts/analyze.py` are included, the agent calls these scripts to derive actual analysis results and reports them to the user.

## Trade-offs Compared with Alternatives

| Comparison Item | `android/skills` | General AI Coding Assistants |
| :--- | :--- | :--- |
| **Knowledge Basis** | Structured data based on official docs | Learned parameters (general knowledge) |
| **Recency** | Immediate reflection via repo updates | Requires model retraining |
| **Expertise** | Specialized in a specific domain (Android) | General-purpose, potentially lacks depth |
| **Executability** | Includes scripts and checklists | Primarily code generation |

**Pros:** By injecting the latest Android-specific guides directly into the agent, it dramatically reduces errors from using outdated APIs, which is common with general LLMs. It also provides objective criteria to verify agent results through checklists and scripts.

**Cons:** It requires the user to manually install and manage skills. There is also a possibility that the agent may not automatically activate the relevant skill or may fail to select the appropriate one if the prompt is ambiguous.

## Security, Licensing, and Adoption Checks

- **Licensing:** This project follows the `Apache License 2.0`. This allows for free commercial use, modification, and distribution, provided that the original copyright notice is included. Check for license compliance when adopting in a corporate environment.
- **Security:** Python scripts included in the `scripts/` folder run in the user's local environment. It is recommended to review the code before executing externally sourced scripts to ensure there are no unintended file access or network requests.
- **Adoption Check:** As stated in the project's `README.md`, AI can make mistakes. Especially when generating code in security-sensitive areas like `device-ai` or `identity`, human-in-the-loop verification is mandatory.

## Limitations and Who Should Use It

**Limitations:**
- **Scope of Automation:** This is not a universal tool that can solve every Android development problem. The provided guidance may be inappropriate if it conflicts with complex business logic or a project's unique architecture.
- **Environmental Dependency:** It relies on specific toolchains like `android-cli`, requiring integration into existing development environments.

**Who Should Use It:**
- **Teams building Android-specialized AI agents:** Ideal for teams looking to increase agent development productivity and produce code that adheres to official guidelines.
- **Developers considering the adoption of the latest Android technologies:** Useful for developers who want to efficiently learn and apply rapidly changing tech stacks like CameraX, Jetpack Compose, and on-device AI with the help of AI.
- **Maintainers of large-scale projects:** If you want to automate build system management or quality guideline compliance, you can use the skills in this repository to maintain consistent code quality.
