## Symptom

When attempting to read or modify a global variable declared outside a function from within that function, the following error occurs.

```python
UnboundLocalError: local variable 'total' referenced before assignment
```

The minimal reproducible code causing the error is as follows.

```python
total = 0

def doB():
    total = total + 1

doB()
```

## Cause

Python considers a variable to be local if an assignment operation (`=`) exists within the function.
Since the statement `total = ...` exists inside function `doB`, Python treats `total` as a local variable.
However, in the statement `total = total + 1`, the `total` on the right-hand side has not yet been assigned as a local variable, so it cannot be referenced.
This results in an error stating that it was referenced before assignment.
While simply reading a global variable (e.g., `print(total)`) is allowed within a function, explicit declaration is required to modify its value.

## Solution

To modify a global variable inside a function, you must explicitly declare that the variable resides in the global namespace using the `global` keyword.

```python
total = 0

def doB():
    global total
    total = total + 1

doB()
print(total)  # 1
```

Adding the `global` keyword at the beginning of the function ensures that the `total` variable inside the function refers to the global variable, resolving the error.

## Alternative Solutions

Instead of modifying the global variable's value inside the function, you can pass the value as an argument and return the result.
This method avoids namespace conflicts by not directly modifying the state of global variables.

```python
def doB(current_total):
    return current_total + 1

total = 0
total = doB(total)
print(total)  # 1
```

## Additional Notes

The `global` keyword is not required when using a global variable as read-only within a function.
It automatically looks up global variables only when there is no assignment operation.

```python
total = 0

def checkTotal():
    print(total)  # Read-only is possible without global declaration

checkTotal()  # Outputs: 0
```

Excessive use of global variables can reduce code readability and make debugging difficult, so it is recommended to utilize classes or module structures whenever possible.
