## Overview

At KB Kookmin Bank I worked on moving an existing ML-based chatbot to generative AI. The existing chatbot gave rule-based answers driven by an in-house BERT model.

## Characteristics of the Existing ML Chatbot

An ML chatbot only serves pre-built answers, so its responses are highly predictable. The limitation is that expressions not in the training data fall back to a default response, and even a similar intent is classified as a separate intent if it is phrased differently.

Because a wrong answer carries a large risk in financial services, keeping the existing predictability as much as possible was a key criterion during the transition.

## What I Found During the Transition

**Handling hallucinations**

When retrieval similarity is low, I set a threshold so that the LLM answer is not used and the system falls back instead.

**Prompt management**

I wrote the system prompt strictly so that the model answers only within the information retrieved from the knowledge base.

**Response speed**

Instead of generating the full response and returning it at once, I streamed the output, which improved the perceived response speed.

## Conclusion

The LLM transition improved how well the chatbot handles queries it could not process before, but verifying the consistency of its answers became even more important. Currently we run ML and LLM together depending on the situation.
