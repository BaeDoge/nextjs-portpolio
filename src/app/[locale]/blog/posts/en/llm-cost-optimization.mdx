Today I'll write up how I reduced LLM API costs.

## Situation

The LLM API cost of an internal tool came in higher than expected. The number of calls was within the expected range, but token usage was high.

## Causes and fixes

**1. A bloated system prompt**

The system prompt was about 1,500 tokens and was included in every call. I removed unnecessary wording and cut it to 400 tokens, with no noticeable difference in output quality.

**2. Sending the entire conversation history**

In multi-turn conversations, the entire history was sent every time. I changed it to keep only the most recent N turns.

```python
MAX_TURNS = 6

def trim(messages: list[dict]) -> list[dict]:
    system = [m for m in messages if m["role"] == "system"]
    rest = [m for m in messages if m["role"] != "system"]
    return system + rest[-MAX_TURNS * 2:]
```

**3. Too much RAG context**

I was including the top 10 chunks as context, but only two or three were actually cited. I set `match_count=4` and raised the similarity threshold.

**4. One model for everything**

The same large model was used for every request. I switched tasks like classification and short summaries to a lightweight model.

```python
def pick_model(task: str) -> str:
    if task in ("classify", "summarize_short"):
        return SMALL_MODEL
    return LARGE_MODEL
```

## Result

The monthly cost dropped by about 60%. Shrinking the system prompt and adjusting the context had the biggest effect.

## Conclusion

The cause of a cost problem was often tokens per call rather than the number of calls. Logging token usage per call helps find the cause.
