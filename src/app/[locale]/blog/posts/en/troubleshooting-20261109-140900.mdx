## Symptom

Passing a string containing a decimal point directly to the `int()` function causes a parsing failure, resulting in a `ValueError`.

<Callout type="warning" title="Error Case">
ValueError: invalid literal for int() with base 10: '23.45678'
</Callout>

This error frequently occurs not only in standard string conversions but also when converting column types in `pandas` DataFrames.

```python
s = '23.45678'
i = int(s)

import pandas as pd

df = pd.DataFrame({'col': ['0.001']})
df['col'].astype(int)
```

![Symptom screenshot](/blogs/troubleshooting-20261109-140900-1.png)

## Cause

The `int()` built-in function performs parsing logic that interprets strings as decimal integer literals. Since strings containing decimal points do not conform to the decimal integer syntax, the parser fails to recognize them and rejects the conversion.

<Callout type="info" title="Note">
The `int()` function does not accept decimal points.
</Callout>

## Solution

Convert the string to a floating-point number (`float`) first to include the decimal value, and then convert it to `int()`.

```python
s = '23.45678'
i = int(float(s))
```

For `pandas` columns, use the `astype()` method to convert to `float` as an intermediate step, and then to `int`.

```python
import pandas as pd

df = pd.DataFrame({'col': ['0.001']})
df['col'] = df['col'].astype(float).astype(int)
```

## Alternative Solutions

Using the `Decimal` class from the `decimal` module allows you to handle floating-point numbers with high precision before converting them to integers.

```python
from decimal import Decimal

s = '23.45678'
i = int(Decimal(s))
```

In a `pandas` environment, you can use `apply` combined with `split` to extract only the part before the decimal point and convert it using `int()`. This method avoids potential floating-point precision issues that may arise during `float` conversion.

```python
import pandas as pd

df = pd.DataFrame({'col': ['0.001']})
df['col'] = df['col'].apply(lambda x: int(x.split('.')[0]))
```

## Additional Notes

Checking the variable type using the `type()` function before type conversion can prevent unexpected errors.

```python
money = "777"
print(type(money))  # <class 'str'>
```

Attempting to perform arithmetic operations directly between a string-type value and an integer-type value results in a `TypeError: must be str, not int`. Ensure types are aligned before performing calculations.

```python
money = "777"
print(int(money) + 333)
```
