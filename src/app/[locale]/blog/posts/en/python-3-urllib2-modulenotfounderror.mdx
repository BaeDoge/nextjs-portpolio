## Symptom

In a Python 3 environment, an error occurs when attempting to call the Python 2 library `urllib2`. A `ModuleNotFoundError: No module named 'urllib2'` is output in code calling `urlopen`.

```python
import urllib2

response = urllib2.urlopen("http://www.google.com")
html = response.read()
print(html)
```

![Symptom screenshot](/blogs/python-3-urllib2-modulenotfounderror-1.png)

## Cause

Python 3 has removed the `urllib2` module and separated its functionality into `urllib.request` and `urllib.error`. Directly calling the existing `urllib2` causes the interpreter to be unable to find the module. Additionally, syntax such as `urllib2.request` is incompatible with Python 3's module structure, causing import itself to fail.

## Solution

Instead of `urllib2`, the `urlopen` function from the `urllib.request` module should be used. Code should be modified to call functions directly using the `from` keyword.

```python
from urllib.request import urlopen
html = urlopen("http://www.google.com/").read()
print(html)
```

![Solution screenshot](/blogs/python-3-urllib2-modulenotfounderror-2.png)

## Alternative Solutions

It is also possible to import the entire module and then call the function by module name. In this case, it must be called in the format `urllib.request.urlopen`.

```python
import urllib.request

response = urllib.request.urlopen("http://www.google.com/")
html = response.read()
print(html)
```

## Additional Notes

`urllib.request` and `urllib.error` replace the functionality of `urllib2` in Python 3. When converting Python 2 code to Python 3, the `2to3` tool can automatically fix import statements.
