## Symptom

When using pandas' `read_csv` function to read a CSV file, the following error occurs:

```python
UnicodeDecodeError: 'utf-8' codec can't decode byte ...
```

By default, `read_csv` attempts to interpret the file as `utf-8` encoded. If the file's actual encoding differs from `utf-8`, this error occurs due to string conversion failure during the parsing process.

## Cause

If the encoding parameter is not explicitly specified, the `read_csv` function uses the default `utf-8`.
If the encoding used when saving the file (e.g., `cp949`, `ISO-8859-1`, `cp1252`, etc.) does not match the encoding expected by pandas, it fails during the process of converting byte sequences into characters.
This frequently occurs with files containing Korean characters, as they are often saved in `cp949` instead of `utf-8`.

## Solution

Resolve the issue by explicitly specifying the file's actual encoding in the `encoding` parameter of the `read_csv` function.
For Korean files, `cp949` or `utf-8` are commonly used.

```python
# Before modification
df = pd.read_csv('filename.csv')

# After modification: Explicitly specify encoding as cp949
df = pd.read_csv('filename.csv', encoding='cp949')
```

## Alternative Solutions

If the exact encoding of the file is unknown or if it cannot be read with a specific encoding, a generic encoding can be used.
`ISO-8859-1` or `latin` encoding has a wide range for mapping bytes to characters, which can bypass the error.
Additionally, `cp1252` can be used in Windows environments.

```python
# Use ISO-8859-1 encoding
df = pd.read_csv('filename.csv', encoding='ISO-8859-1')

# Use latin encoding
df = pd.read_csv('filename.csv', encoding='latin')
```

## Additional Notes

To check the file's encoding, you can use the `file -i <filename>` command on Linux or the `file -I <filename>` command on macOS.
When saving files using `to_csv`, it is generally recommended to use `utf-8` encoding for better compatibility.
For background knowledge on encoding, it is advisable to refer to resources such as 'What every developer should know about unicode and character sets'.
