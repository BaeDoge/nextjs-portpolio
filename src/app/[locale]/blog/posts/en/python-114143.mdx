## Symptom

Accessing a list at an index outside its valid range raises an `IndexError`.

<Callout type="warning" title="Error Scenario">
IndexError: list index out of range
</Callout>

The following code raises an error because it attempts to access index 4 in a list that contains only three elements.

```python
a = ['123', '2', 4]
print(a[4])
```

![Symptom screenshot](/blogs/python-114143-1.png)

## Cause

Python list indices start at 0, and the valid indices for a list of length N range from 0 to N-1. If the requested index falls outside this range, the interpreter detects the absence of data at that position and raises an `IndexError`.

Reference materials indicate that this error frequently occurs due to off-by-one calculation errors in logic or when external data is shorter than expected.

## Solution

Aligning with Python's philosophy of "It is easier to ask for forgiveness than permission," use a `try-except` block to catch the error and assign a default value.

```python
a = ['123', '2', 4]

try:
    b = a[4]
except IndexError:
    b = 'sss'

print(b)  # 'sss'
```

## Alternative Solutions

Instead of `try-except`, you can use a conditional statement (`if`) to validate the index beforehand. This is a defensive programming approach that prevents access before an error occurs.

```python
a = ['123', '2', 4]
index = 4

if index < len(a):
    b = a[index]
else:
    b = 'sss'

print(b)  # 'sss'
```

## Additional Notes

Habitually checking the length of a list before accessing its index is the most effective way to prevent `IndexError`.

<Steps>
<Step title="Identify the Error Location">
Print the list's length (`len()`) and the index you intend to access immediately above the erroneous code to compare the ranges.
</Step>
<Step title="Validate Index Range">
Verify that the index is greater than or equal to 0 and less than the list length before extracting the value.
</Step>
</Steps>
