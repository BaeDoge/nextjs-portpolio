## Symptom

An error occurs when trying to read a global variable defined outside a function from within the function, if there is an assignment operation to that variable somewhere inside the function.

<Callout type="warning" title="Error Situation">
UnboundLocalError: local variable 'c' referenced before assignment
</Callout>

The minimum code to reproduce the error is as follows.

```python
a, b, c = (1, 2, 3)

def test():
    print(a)
    print(b)
    print(c)
    c += 1

test()
```

In the above code, commenting out the `c += 1` line allows it to work normally, but uncommenting it causes an error at the `print(c)` step.

![Symptom screenshot](/blogs/unboundlocalerror-120320-1.png)

## Cause

When compiling a function, Python scans all assignment statements in the function body to determine the scope of variables.

If a statement that assigns a value to a variable inside the function is found (e.g., `c = ...`, `c += 1`), the variable is treated as a local variable rather than a global variable.

As a result, even before `c += 1` is called during function execution, `c` is already considered declared as a local variable, so it is judged as referencing an uninitialized local variable.

## Solution

To modify a global variable inside a function, you must explicitly specify the variable's scope using the `global` keyword.

```python
a, b, c = (1, 2, 3)

def test():
    global c
    print(a)
    print(b)
    print(c)
    c += 1

test()
```

By specifying `global c` at the beginning of the function, `c` refers to the module-level global variable rather than a local variable.

## Alternative Solutions

You can refactor the code into a pure function structure using function parameters and return values.

This method makes data flow clear without depending on global state, facilitating maintenance.

```python
def increment_pure(current_count):
    return current_count + 1

c = 3
c = increment_pure(c)
```

Use the `nonlocal` keyword when you need to modify a local variable of an outer function from within a nested function (closure).

```python
def outer_function():
    total = 100

    def inner_function():
        nonlocal total
        total -= 10
        print("남은 수량:", total)

    inner_function()

outer_function()
```

## Additional Notes

Simply reading a variable inside a function (e.g., `print`, `return`) allows you to reference the global variable without the `global` keyword.

Regardless of where the assignment operation is in the function body, an assignment statement in the function isolates the variable as a local variable.
