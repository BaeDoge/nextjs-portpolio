## Problem

A gene string consists of 8 characters, each being 'A', 'C', 'G', or 'T'. A single mutation is a change of one character in the string to another character. `bank` stores a list of valid mutation strings, and any string involved in a mutation must be present in `bank`. `startGene` may be valid but not necessarily in `bank`. Determine the minimum number of mutations required to transform `startGene` into `endGene`, returning -1 if the transformation is impossible.

## Approach

Use BFS to find the shortest path from `startGene` to `endGene`. At each step, iterate over each position of the current string and try all four possible characters; if the resulting string is in `bank` and not visited, add it to the queue. When `endGene` is reached, return the current step count.

```python
from collections import deque

def minMutation(startGene: str, endGene: str, bank: list[str]) -> int:
    if startGene == endGene:
        return 0

    bank_set = set(bank)
    if endGene not in bank_set:
        return -1
    visited = {startGene}
    q = deque([(startGene, 0)])
    chars = {'A', 'C', 'G', 'T'}

    while q:
        gene, steps = q.popleft()
        if gene == endGene:
            return steps
        # change one character
        for i in range(len(gene)):
            for c in chars:
                if c == gene[i]:
                    continue
                nxt = gene[:i] + c + gene[i+1:]
                if nxt in bank_set and nxt not in visited:
                    visited.add(nxt)
                    q.append((nxt, steps + 1))
    return -1
```

## Solution

The above BFS code computes the minimum number of mutations. `bank_set` provides O(1) lookups, and `visited` set prevents duplicate exploration. The search continues until `endGene` is reached or the queue is empty. There are at most 3 replacement characters for each of the L positions of each visited gene. Creating each candidate string takes O(L) time, so the worst-case time complexity is O(N·L²). The visited set and queue store gene strings, giving O(N·L) auxiliary space.

```python
# Example execution
print(minMutation("AACCGGTT", "AACCGGTA", ["AACCGGTA"]))  # 1
print(minMutation("AACCGGTT", "AAACGGTA", ["AACCGGTA","AACCGCTA","AAACGGTA"]))  # 2
```

## Alternative Approaches

- **Bidirectional BFS:** Start BFS from both `startGene` and `endGene` simultaneously and find a meeting point, reducing the search space. This can reduce the number of explored states in practice. The worst-case time complexity still includes candidate-string construction and is O(N·L²).
- **DFS + Memoization:** For each string, explore all reachable strings and store the shortest path to `endGene`. This approach is similar to BFS for small banks but may suffer from performance degradation due to repeated exploration in larger banks.

## Additional Notes

- If `endGene` is not in `bank`, the transformation is impossible, so return -1.
- If `startGene` and `endGene` are the same, return 0.
- It is valid for `bank` not to contain `startGene`; BFS relies only on `bank_set`.
