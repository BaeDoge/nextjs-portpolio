오늘은 KB국민은행 AI 금융비서 서비스에서 진행한 클라우드 비용 최적화 사례를 정리해 보겠습니다.

## 상황

영업 시간(평일 9시~18시)에 트래픽이 집중되고, 야간과 주말에는 트래픽이 거의 없는 패턴이었습니다. 파드를 24시간 동일 스펙으로 유지할 경우 비사용 시간대에도 동일한 비용이 발생하는 문제가 있었습니다.

## 해결 1 — Lambda 스케줄링

AWS Lambda를 사용해 시간대별로 파드 수를 조정했습니다.

```python
def scale_eks_deployment(replicas: int, deployment: str):
    k8s_client.patch_namespaced_deployment_scale(
        name=deployment,
        namespace="production",
        body={"spec": {"replicas": replicas}}
    )
```

## 해결 2 — HPA 설정

예측 불가능한 트래픽 증가에 대응하기 위해 HPA를 함께 구성했습니다.

```yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
spec:
  minReplicas: 2
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 70
```

## 결론

정기적인 패턴은 Lambda 스케줄링으로, 돌발 트래픽은 HPA로 대응하는 구조를 적용했습니다. 임계값과 대기 시간 등의 세부 수치는 실제 트래픽 데이터를 기준으로 조정했습니다.
