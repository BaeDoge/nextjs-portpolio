오늘은 ETRI 인턴 기간 중 진행한 PPG 기반 혈압 추정 모델 개발 사례를 정리해 보겠습니다.

## 배경

PPG(광용적맥파)는 광센서를 이용해 비침습적으로 측정 가능한 신호로, 기존 커프 방식 대비 연속 측정이 가능하다는 장점이 있어 혈압 추정 연구에 활용되고 있습니다.

## 데이터

MIMIC-III 데이터셋(중환자실 생체신호 데이터, 약 1,600명)을 사용했습니다. 환자당 최대 100개의 8초 이상 연속 구간을 추출하고 노이즈 구간을 제거하여 총 101,087개의 데이터를 확보했습니다.

## 모델 구조

초기에는 단일 LSTM 구조로 시작했으나, PPG 신호가 파형 형태(Morphology)와 시간 영역(Time-Domain) 특성이라는 서로 다른 정보를 포함하고 있어 단일 입력으로는 두 특성을 동등하게 반영하기 어려웠습니다.

이에 따라 3-Branch 구조로 변경했습니다.

```text
[PPG 신호] → Branch 1 (CNN-LSTM) →┐
[PPG 신호] → Branch 2 (CNN-LSTM) →├→ Dense → SBP
[TD 특성]  → Branch 3 (DNN)      →┘
```

Branch 1, 2는 서로 다른 수용 영역으로 파형 형태를 처리하고, Branch 3은 시간 영역 특성(맥박 주기, 상승/하강 시간 등)을 처리합니다.

## 결과

단일 CNN-LSTM 구조에서 MAE 9.98 mmHg였던 결과가, 3-Branch 구조 적용 후 8.92 mmHg로 약 12% 개선되었습니다. 개선 폭은 Time-Domain Branch 추가 시 가장 크게 나타났습니다.

## 결론

모델 구조 설계 이전에 입력 신호가 포함하는 정보의 종류를 파악하는 것이 성능 개선에 중요한 요소였습니다. 해당 연구는 한국통신학회에 논문으로 발표했습니다.
