오늘은 처음으로 진행한 오픈소스 기여 경험을 정리해 보겠습니다.

## 배경

오픈소스 기여는 필요성을 느끼면서도 진입장벽에 대한 우려로 미뤄왔던 항목이었습니다.

## 진행 과정

평소 사용하던 Flowise의 한국어 번역 파일에 누락된 항목이 있는 것을 확인하고 이를 기여 대상으로 선정했습니다.

```bash
# 1. Fork & Clone
gh repo fork FlowiseAI/Flowise --clone
cd Flowise

# 2. 브랜치 생성
git checkout -b fix/korean-i18n-improvements

# 3. 번역 파일 수정
# packages/ui/src/i18n/locales/ko.json

# 4. 커밋 & 푸시
git commit -m "fix(i18n): add missing Korean translations for chatflow and agentflow"
git push origin fix/korean-i18n-improvements

# 5. PR 생성
```

PR 생성 후 표현 수정 및 추가 파일 적용 요청을 받았고, 이를 반영하여 머지되었습니다.

## 확인한 사항

- 리뷰어의 피드백은 구체적이고 협조적인 방식으로 제공되었습니다.
- PR 설명과 커밋 메시지를 명확하게 작성하면 영어 의사소통에 대한 부담이 크지 않았습니다.
- 코드 변경 없이 번역 파일 수정만으로도 Contributors 목록에 등록되었습니다.

## 결론

작은 단위의 기여부터 시작하는 것이 진입장벽을 낮추는 데 효과적이었습니다. 다음 단계로는 코드 수준의 기여를 진행할 계획입니다.
