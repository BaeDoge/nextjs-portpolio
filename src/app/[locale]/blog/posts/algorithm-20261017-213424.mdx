## 문제

중복 원소가 있는 이진 탐색 트리(BST)에서 가장 자주 나타나는 요소인 모드(mode)를 모두 반환하는 문제입니다. 트리가 여러 모드를 가질 경우 순서에 상관없이 반환하면 됩니다. BST의 정의는 왼쪽 서브트리의 키가 현재 노드보다 작거나 같고, 오른쪽 서브트리의 키가 크거나 같음을 의미합니다. 노드 수는 최대 10^4개이며, 노드 값의 범위는 -10^5에서 10^5 사이입니다. 추가적으로 상수 공간 복잡도를 요구하는 Follow up가 있습니다.

## 접근 방법

이진 탐색 트리의 중위 순회(In-order Traversal)는 노드 값을 오름차순으로 방문하게 됩니다. 이 특성을 이용하면 동일한 값들이 연속적으로 나타나므로, 별도의 해시맵이나 정렬 없이 현재 값의 연속 등장 횟수를 추적하여 최빈값을 찾을 수 있습니다. 전역 또는 인스턴스 변수를 사용하여 현재 값(currentVal), 현재 값의 등장 횟수(currentCount), 최대 등장 횟수(maxCount), 그리고 결과 모드를 저장하는 리스트를 관리합니다. 중위 순회 과정에서 현재 값이 이전 값과 같으면 currentCount를 증가시키고, 다르면 currentCount를 1로 초기화합니다. 이후 currentCount가 maxCount와 비교하여 크면 maxCount를 갱신하고 결과 리스트를 초기화한 후 현재 값을 추가합니다. 같으면 현재 값을 결과 리스트에 추가합니다.

## 풀이

```python
class Solution:
    def findMode(self, root: Optional[TreeNode]) -> List[int]:
        self.current_val = None
        self.current_count = 0
        self.max_count = 0
        self.modes = []

        def inorder(node):
            if not node:
                return
            inorder(node.left)
            
            # 현재 노드 값 처리
            if self.current_val is not None:
                if node.val == self.current_val:
                    self.current_count += 1
                else:
                    self.current_count = 1
                    self.current_val = node.val
            else:
                self.current_val = node.val
                self.current_count = 1

            # 최빈값 갱신 로직
            if self.current_count > self.max_count:
                self.max_count = self.current_count
                self.modes = [self.current_val]
            elif self.current_count == self.max_count:
                self.modes.append(self.current_val)
                
            inorder(node.right)

        inorder(root)
        return self.modes
```

시간 복잡도: O(N) (모든 노드를 한 번 방문). 공간 복잡도: O(H) (재귀 호출 스택 깊이, H는 트리 높이).

## 다른 풀이 방법

해시맵(Counter)을 사용하여 모든 노드의 등장 횟수를 세는 방법이 있습니다. 중위 순회 대신 어떤 순회든 가능하며, 각 노드의 값을 카운터에 저장한 후 최대 값을 갖는 키들을 추출합니다. 이 방법은 시간 복잡도 O(N)이지만 공간 복잡도가 O(N)으로 증가합니다. Follow up에서 요구한 상수 공간(O(1)) 해결에는 부적합하지만, 구현이 직관적이고 일반 트리에도 적용 가능하다는 장점이 있습니다.

## 추가 참고사항

Follow up의 상수 공간 해결은 재귀 호출 스택을 사용하지 않는 Morris Traversal 기법을 활용하면 가능합니다. Morris Traversal은 트리의 리프 노드 중 하나를 임시로 루트로 연결하여 순회 경로를 만들어내므로 추가 메모리를 사용하지 않습니다. 이를 적용하면 O(1) 공간 복잡도로 모드를 찾을 수 있습니다. 또한, 문제에서 BST의 정의를 '왼쪽 <= 노드 <= 오른쪽'으로 제시했으므로, 중복 값이 존재할 수 있음을 유의해야 합니다.
