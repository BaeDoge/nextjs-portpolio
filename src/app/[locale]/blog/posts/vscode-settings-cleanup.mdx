## 왜

새 노트북을 세팅하면서 기존 설정을 그대로 옮기려다가,
`settings.json`을 열어보고 그만뒀습니다. 300줄이 넘었고
절반은 뭘 하는 건지 기억이 안 났습니다.

빈 상태로 시작해서, 불편할 때만 한 줄씩 추가하기로 했습니다.

## 2주 뒤 남은 설정

```jsonc
{
  // 저장할 때 포맷 — 이건 첫날 바로 넣었다
  "editor.formatOnSave": true,

  // 공백 보이기. 들여쓰기 섞인 파일 디버깅할 때 필요
  "editor.renderWhitespace": "boundary",

  // 파일 탐색기에서 빌드 산출물 숨기기
  "files.exclude": {
    "**/__pycache__": true,
    "**/.pytest_cache": true,
    "**/node_modules": true
  },

  // 검색에서 제외 — 위와 별개다. 이걸 몰라서 한참 헤맸다
  "search.exclude": {
    "**/dist": true,
    "**/.next": true,
    "**/package-lock.json": true
  },

  // 미니맵 끔. 화면 좁아지는 게 더 손해였다
  "editor.minimap.enabled": false,

  // 자동 저장 끔 — 저장 시점을 내가 정하고 싶다
  "files.autoSave": "off"
}
```

끝입니다. 20줄 정도.

## 지운 것 중 기억나는 것

- 폰트 리가처: 예뻐 보였는데 `!=`가 하나로 붙어 보여서 오히려 헷갈렸습니다
- 브래킷 색상 커스텀: 기본값이 이미 충분했습니다
- 온갖 테마 설정: 테마 하나 정하고 나니 나머지는 불필요했습니다

## 확장도 같이 정리

확장은 35개에서 9개가 됐습니다.
기준은 "지난 2주간 한 번이라도 의식적으로 썼는가"였습니다.

의외로 많은 확장이 "설치했다는 사실"만 기억나고
실제로 기능을 쓴 적은 없었습니다.

## 느낀 점

설정이 쌓이는 건 자연스러운데, 주기적으로 비우지 않으면
"왜 이렇게 되어 있지"를 설명 못 하는 상태가 됩니다.

내년에도 한 번 비울 생각입니다.
