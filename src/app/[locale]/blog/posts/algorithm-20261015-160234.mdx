## 문제

정수 배열 `nums`가 주어졌을 때, 인덱스 `i < j < k`를 만족하면서 `nums[i] < nums[j] < nums[k]`를 만족하는 세 수의 부분수열(삼중수)이 존재하면 `true`, 그렇지 않으면 `false`를 반환해야 합니다. 배열의 길이는 최대 5 * 10^5이며, 요소의 값은 32비트 정수 범위 내에 있습니다. 문제의 핵심 요구사항은 O(n)의 시간 복잡도와 O(1)의 공간 복잡도를 만족하는 해결책을 제시하는 것입니다.

## 접근 방법

이 문제는 최장 증가 부분수열(LIS)의 특수한 경우(길이 3)로 볼 수 있으나, 전체 LIS를 구하는 것은 O(n log n) 또는 O(n^2)이 소요되어 O(n) 요구사항을 충족하지 못합니다. 따라서 두 개의 변수 `first`와 `second`를 유지하며 단일 순회로 해결할 수 있는 탐욕(Greedy) 접근법을 사용합니다. `first`는 현재까지 발견된 가장 작은 수를, `second`는 `first`보다 큰 수 중 가장 작은 수를 의미합니다. 새로운 수가 `second`보다 크면 삼중수열이 완성된 것이므로 즉시 `true`를 반환합니다. 새로운 수가 `first`보다 작으면 `first`를 갱신하고, `first`보다 크지만 `second`보다 작으면 `second`를 갱신합니다. 이 과정은 배열을 한 번만 순회하므로 O(n) 시간 복잡도를 가집니다.

## 풀이

```python
class Solution:
    def increasingTriplet(self, nums: List[int]) -> bool:
        first = float('inf')
        second = float('inf')
        
        for num in nums:
            if num <= first:
                first = num
            elif num <= second:
                second = num
            else:
                return True
                
        return False
```

시간 복잡도: O(n). 배열의 모든 요소를 한 번씩 순회하며 상수 시간 연산만 수행합니다. 공간 복잡도: O(1). `first`와 `second` 두 개의 변수만 사용하므로 추가 메모리 공간을 일정하게 사용합니다.

## 다른 풀이 방법

1. DP (Dynamic Programming) 접근: 각 인덱스 `i`에 대해 `i`보다 앞에 있는 수 중 가장 작은 수와 `i`보다 뒤에 있는 수 중 가장 큰 수를 미리 계산하는 방법입니다. 이를 위해 왼쪽에서 오른쪽으로 스캔하며 각 위치 이전의 최소값을 저장하는 배열과, 오른쪽에서 왼쪽으로 스캔하며 각 위치 이후의 최대값을 저장하는 배열을 생성할 수 있습니다. 이 경우 시간 복잡도는 O(n)이지만, 두 개의 보조 배열을 사용하므로 공간 복잡도가 O(n)이 되어 문제의 O(1) 공간 제약조건을 만족하지 못합니다. 2. LIS 알고리즘 활용: 일반적인 최장 증가 부분수열 알고리즘을 사용하여 길이 3인 LIS가 존재하는지 확인할 수 있습니다. 이 방법은 시간 복잡도 O(n log n)을 가지므로 O(n) 요구사항을 충족하지 못합니다.

## 추가 참고사항

탐욕 알고리즘에서 `num <= first` 조건에서 등호를 포함하는 이유는, 동일한 값을 여러 번 사용하여 삼중수열을 만들 수 없도록 하기 위함입니다. 만약 `first`가 2이고 현재 수가 2라면, `first`를 갱신하지 않고 `second`도 갱신하지 않아야 합니다. 등호를 포함하지 않고 `num < first`로 처리하면, 동일한 값이 `first`와 `second`에 중복으로 할당되어 잘못된 삼중수열 탐색으로 이어질 수 있습니다. 또한, `second`가 갱신될 때 `first`는 반드시 `second`보다 작아야 하는 조건이 내포되어 있으므로, `second`가 갱신되었다는 것은 이미 `first`보다 큰 수가 하나 존재했다는 것을 의미합니다.
