## 문제

0으로 시작하는 정수 배열 nums에서 피크 요소를 찾아 인덱스를 반환해야 합니다. 피크 요소는 양쪽 인접 원소보다 엄격히 큰 원소를 의미합니다. 배열의 양 끝은 음의 무한대(-inf)로 가정하므로, 경계 원소도 피크가 될 수 있습니다. 배열에 여러 피크가 존재할 경우 그중 하나의 인덱스를 반환하면 됩니다. 알고리즘은 O(log n) 시간 복잡도를 가져야 합니다.

## 접근 방법

O(log n) 시간 복잡도 요구사항은 이분 탐색(Binary Search)을 사용해야 함을 시사합니다. 배열이 완전히 정렬되어 있지 않아도 이분 탐색이 가능한 이유는, 중간 지점(mid)에서 오른쪽 neighbor(mid+1)와 비교했을 때 증가하는 방향이면 반드시 오른쪽에 피크가 존재하고, 감소하는 방향이면 왼쪽에 피크가 존재하기 때문입니다. 이를 통해 탐색 범위를 절반씩 줄일 수 있습니다.

## 풀이

이분 탐색을 적용합니다. left는 0, right는 nums.length - 1로 초기화합니다. left가 right보다 작거나 같은 동안 반복합니다. mid를 계산하고, nums[mid]가 nums[mid+1]보다 작은 경우, 오른쪽으로 증가하는 경사가 있으므로 left를 mid + 1로 이동합니다. 그렇지 않은 경우(즉, nums[mid]가 nums[mid+1]보다 크거나 같은 경우), 왼쪽에 피크가 있거나 mid 자체가 피크이므로 right를 mid로 이동합니다. 루프가 종료될 때 left와 right는 같은 인덱스를 가리키며, 이것이 피크 요소의 인덱스가 됩니다.

```python
def findPeakElement(nums):
    left = 0
    right = len(nums) - 1
    
    while left < right:
        mid = (left + right) // 2
        if nums[mid] < nums[mid + 1]:
            left = mid + 1
        else:
            right = mid
            
    return left
```

시간 복잡도: O(log n), 공간 복잡도: O(1)

## 다른 풀이 방법

선형 탐색(Linear Search)을 사용하면 O(n) 시간에 해결할 수 있습니다. 인덱스 0부터 n-1까지 순회하며 현재 원소가 다음 원소보다 큰지 확인하거나, 마지막 원소인 경우 피크로 간주합니다. 이 방법은 코드가 단순하지만 문제에서 요구하는 O(log n) 조건을 만족하지 못합니다.

## 추가 참고사항

nums[i] != nums[i+1]이라는 제약 조건이 있으므로, 평지(plateau)를 고려할 필요가 없습니다. 이분 탐색의 핵심은 '어느 방향에 반드시 피크가 존재한다'는 귀류법을 이용하는 것입니다. nums[-1]과 nums[n]이 -inf로 가정되므로, 항상 최소 하나의 피크가 존재함이 보장됩니다.
