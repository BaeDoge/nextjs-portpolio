## 1. 청크 구성 방식

금융 FAQ 도메인에서는 문자 수 기반 분할보다 질문-답변 단위 청킹이 검색 정확도 면에서 효과적이었습니다.

```python
def chunk_by_qa(document: str) -> list[str]:
    chunks = []
    qa_pairs = re.split(r'\n(?=Q:)', document)
    for pair in qa_pairs:
        if pair.strip():
            chunks.append(pair.strip())
    return chunks
```

## 4. 스트리밍 처리

```typescript
const stream = await groq.chat.completions.create({
  model: "llama-3.3-70b-versatile",
  messages: [...],
  stream: true,
});
```

`stream: true` 설정을 통해 응답을 실시간으로 출력함으로써 체감 대기 시간을 단축했습니다.
