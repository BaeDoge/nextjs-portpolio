오늘은 Claude Code 익스텐션을 3개월 사용하며 정리한 내용을 공유해 보겠습니다.

## 배경

설치 초반에는 유용해 보였던 익스텐션 중 실제로 지속 사용한 항목이 많지 않아, 사용 현황을 정리했습니다.

## 유지한 항목

**1. 프로젝트 컨텍스트 파일**

레포 루트에 프로젝트 컨벤션을 기록해두는 방식으로, 반복적인 설명을 줄이는 데 효과적이었습니다.

```markdown
- 이 프로젝트는 Flask + MySQL, ORM 미사용
- 로그는 구조화 로깅(JSON) 사용, print() 사용 금지
- 테스트는 pytest, 파일명은 test_*.py
```

**2. 터미널 통합**

별도 창 전환 없이 작업할 수 있어 작업 효율이 개선되었습니다.

## 제외한 항목

**자동 커밋 메시지 생성**

diff 내용을 서술하는 수준에 그쳐, 변경 이유를 파악하기 어려웠습니다.

```
- Update user_service.py to add validation logic and modify error handling
```

**실시간 인라인 제안**

작업 흐름을 방해하는 경우가 많아 비활성화했습니다.

## 결론

도구 도입 시 "없으면 작업이 불가능한 것"과 "있으면 편의성이 높아지는 것"을 구분하는 기준이 필요하다고 판단했습니다. 후자가 누적되면 관리 비용이 효용을 상회할 수 있습니다.
