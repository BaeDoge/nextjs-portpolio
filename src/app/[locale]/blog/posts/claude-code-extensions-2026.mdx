## 왜 정리하게 됐나

익스텐션을 깔 때는 다 좋아 보입니다. 3개월 지나고 나니 실제로 매일 여는 건 몇 개 없더군요.
설정 파일을 정리하다가 "이거 언제 깔았지" 싶은 게 너무 많아서, 한 번 솎아냈습니다.

## 살아남은 것

**1. 프로젝트 단위 컨텍스트 파일**

익스텐션이라기보단 관례에 가깝지만, 이게 제일 컸습니다.
레포 루트에 프로젝트 규칙을 적어두니 "우리는 이 컨벤션 씁니다"를 매번 설명할 필요가 없어졌습니다.

```markdown
- 이 프로젝트는 Flask + MySQL. ORM은 쓰지 않고 raw query를 씁니다.
- 로그는 전부 구조화 로깅(JSON). print() 금지.
- 테스트는 pytest, 파일명은 test_*.py
```

처음엔 이런 걸 굳이 적어야 하나 싶었는데, 적어두고 나니 리뷰에서 지적할 일이 확실히 줄었습니다.

**2. 터미널 통합**

별도 창을 안 띄워도 되는 게 생각보다 큽니다.
특히 로그 보면서 수정할 때, 창 왔다갔다 하는 시간이 사라집니다.

## 지운 것

**자동 커밋 메시지 생성**

처음 일주일은 신기했습니다. 그런데 커밋 메시지가 전부 "diff를 서술한 문장"이 되더군요.

```
- Update user_service.py to add validation logic and modify error handling
```

diff를 보면 알 수 있는 내용입니다. 정작 필요한 "왜"는 안 들어갑니다.
결국 직접 쓰는 게 빨라서 껐습니다.

**실시간 인라인 제안**

타이핑 중에 계속 뜨는 게 집중을 끊습니다. 개인 취향이겠지만 저는 안 맞았습니다.

## 남은 생각

도구가 늘어날수록 "이 도구가 없으면 못 하는 일"과 "있으면 조금 편한 일"을 구분해야 합니다.
후자가 너무 많아지면 설정 유지비가 도구 효용을 넘어섭니다.

3개월 뒤에 또 솎아낼 예정입니다.
